# نور القرآن — NoorQuran

مشروع قرآني مجاني يجمع تطبيق Android وموقع الويب، صدقة جارية عن روح الوالد وعن روح يحيى يحيى راجح تميم.

## نقاط الدخول

- **بوابة الويب:** مجلد `website/`؛ تجمع روابط المصحف والتلاوات والمكتبة والتنزيلات ومصادر التطبيق.
- **الموقع الشامل:** [noor-quran-yahya.darkfig128.chatgpt.site](https://noor-quran-yahya.darkfig128.chatgpt.site).
- **تطبيق Android:** مصدر Flutter في `lib/` وملفات المحتوى في `assets/`. راجع [تعليمات البناء](docs/BUILD.md).
- **الخصوصية والمحتوى:** راجع [وثيقة الخصوصية والإهداء](docs/DEDICATION_AND_PRIVACY.md) و[مصدر القرآن](docs/QURAN_SOURCE.md).

## حالة الإصدارات

بوابة GitHub توحّد الوصول وتوجّه إلى موقع Sites للأقسام الكاملة. ملفات المصدر المنشورة داخل مشروع Sites لا تُزامَن تلقائيًا إلى هذا المستودع؛ راجع [خطة توحيد مصدر الويب](docs/WEBSITE_INTEGRATION.md) قبل إصدار تغييرات ويب.

لا يوجد APK عام نهائي معتمد. لا تنشر نسخة تجريبية على أنها إصدار متجر أو نسخة مختبرة على أجهزة حقيقية.

## البناء والنشر

تحتوي `.github/workflows/` على إجراءات بناء Android ونشر صفحات الويب عبر GitHub Pages. نشر صفحات الويب يبدأ عند دمج التغييرات في `main`؛ طلبات المراجعة لا تغيّر الموقع المنشور تلقائيًا.

## الخصوصية وحقوق المحتوى

الاسم والهاتف والبريد الإلكتروني اختيارية. يمكن قراءة القرآن دون حساب. لا تُرسل البيانات الشخصية إلى خادم دون إشعار واضح وموافقة مناسبة. حقوق الكود منفصلة عن حقوق المصاحف والتفسير والتلاوات؛ يجب اتباع تراخيص أصحاب المحتوى.
