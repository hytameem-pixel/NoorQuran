# نور القرآن — NoorQuran

مشروع تطبيق قرآني مجاني، صدقة جارية على روح الوالد وعلى روح يحيى يحيى راجح تميم.

**الحالة:** مشروع تطويري، وليس تطبيق APK جاهزًا بعد. لا يُنشر كناتج نهائي حتى اجتياز الفحوصات وإضافة القرآن الموثق.

## الخصوصية
الاسم والهاتف والبريد الإلكتروني **اختيارية**. يمكن قراءة القرآن دون حساب. البيانات الشخصية لا تُجمع أو تُرسل إلى خادم دون إشعار واضح وموافقة مناسبة.

## البناء
توجد عملية GitHub Actions لبناء APK مع فحص المحتوى والكود والاختبارات. تُوقف عملية البناء إذا غابت حزمة القرآن الموثقة. راجع `docs/BUILD.md`.

## حقوق المحتوى
حقوق كود التطبيق تختلف عن حقوق المصاحف والتفسير والتلاوات. يجب اتباع تراخيص أصحاب المحتوى.
