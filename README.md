# نور القرآن — NoorQuran

مشروع قرآني مجاني يجمع موقع الويب وتطبيق Android، صدقة جارية عن روح الوالد وعن روح يحيى يحيى راجح تميم.

## موقع الويب

يحتوي `website/` على نسخة الويب الثابتة المأخوذة من مصدر Sites، وتشمل المصحف والتلاوات والمكتبة الإسلامية وقسم الأطفال وصفحات التطبيقات والتنزيلات. يعمل التنقل بالعربية واتجاه RTL، وتُستخدم مسارات مجلدات متوافقة مع GitHub Pages مثل `/apps/` و`/library/`.

تم استيراد ملفات الموقع من مصدر Sites عند الإصدار 14. حزم APK وZIP الكبيرة ليست داخل المستودع؛ تبقى روابطها على استضافة Sites الأصلية لتقليل حجم GitHub Pages. تفاصيل الملفات والمزامنة في [وثيقة التكامل](docs/WEBSITE_INTEGRATION.md).

## تطبيق Android

مصدر Flutter في `lib/`، وملفات القرآن في `assets/`. راجع [تعليمات البناء](docs/BUILD.md). لا يوجد APK عام نهائي معتمد؛ يجب وصف ملفات الاختبار بحالتها الفعلية وعدم اعتبارها إصدار متجر أو نسخة مختبرة على أجهزة حقيقية.

## الخصوصية وحقوق المحتوى

الاسم والهاتف والبريد الإلكتروني اختيارية. يمكن قراءة القرآن دون حساب. لا تُرسل البيانات الشخصية إلى خادم دون إشعار واضح وموافقة مناسبة. حقوق الكود منفصلة عن حقوق المصاحف والتفسير والتلاوات؛ يجب احترام المصدر والترخيص المبين لكل مادة.

## النشر

سير عمل GitHub Pages ينشر `website/` عند دمج التغييرات في `main`. طلبات المراجعة لا تنشر تلقائيًا إلى الموقع الأصلي في Sites. لا تُدمج تعديلات النشر النهائي قبل مراجعتها واعتمادها.
