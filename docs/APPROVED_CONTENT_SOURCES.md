# سياسة اعتماد مصادر نور القرآن — سجل التحقق

موافقة مالك المشروع بتاريخ 2026-10-24: استخدام المصادر الإسلامية الموثوقة المتاحة قانونيًا للتوزيع، مع الإسناد الصريح للمؤلف والجهة الناشرة.

## المصادر التي ثبت ترخيص بياناتها
1. نص القرآن العثماني: **Tanzil Project**، الترخيص CC BY 3.0 بشروط نسبة المصدر وعدم تعديل النص. بيانات الآيات الأصلية متضمنة في التطبيق.
2. فهرسة مصحف المدينة برواية حفص (بدايات الصفحات والأجزاء وأرباع الأحزاب): **quran-center/quran-meta**، ترخيص MIT، https://github.com/quran-center/quran-meta . البيانات مضمنة مع ذكر المصدر.
3. مشروع risan/quran-json، ترخيص CC BY-SA 4.0، https://github.com/risan/quran-json — مصدر محتمل للترجمات فقط؛ لا يجوز افتراض أن كل تفسير/ترجمة داخله خاضع للترخيص ذاته دون مراجعة إسناد النص الفردي.

## مصادر قيد التحقق — لا يجوز استيرادها تلقائيًا
| المحتوى | شروط القبول |
|---|---|
| التفسير الميسر | اسم المحقق/الناشر، طبعة محددة، تصريح بإعادة توزيع النص كاملًا داخل APK، ترقيم الآيات ومراجعة عينة علمية |
| معاني الكلمات | المعجم والمؤلف/الناشر، حق النسخ الإلكتروني، ربط الكلمة بالآية والموضع |
| الأذكار والأدعية | مصدر نص كل ذكر، درجة الحديث أو الإحالة الدقيقة، طبعة وترخيص قابل للتوزيع |
| صحيح البخاري | نص طبعة مضبوطة، أرقام الأحاديث، توثيق المحقق وحقوق النسخة الرقمية |
| صحيح مسلم | نص طبعة مضبوطة، أرقام الأحاديث، توثيق المحقق وحقوق النسخة الرقمية |
| رياض الصالحين | نص محقق مع الأبواب والأرقام والتخريج وترخيص النسخة الرقمية |
| تلاوات القراء | هوية القارئ، مالك التسجيل، موافقة مكتوبة على النسخ والبث داخل التطبيق والتنزيل والتخزين دون اتصال |

**مهم:** كون القرآن والحديث من التراث الإسلامي لا يعني أن التسجيلات الصوتية والتحقيقات الحديثة وملفات الناشرين كلها مباحة النسخ والتوزيع. الوصول المجاني عبر موقع أو API لا يمنح تلقائيًا ترخيصًا لتضمين الملفات في APK.

## قواعد تنفيذية
- الاحتفاظ باسم المصدر، الترخيص، نسخة المصدر وتاريخ الاستيراد وبصمة SHA-256 لكل ملف.
- عدم إظهار أي نص على أنه تفسير أو حديث موثق حتى يجتاز التدقيق.
- تقديم المحتوى دون حساب أو تتبع، وإتاحة الاستخدام دون اتصال حيث تسمح الحقوق.
- إضافة اختبار تحقق آلي من عدد السور والآيات ومفاتيح الربط ومنع التكرار/الفقد.
- مراجعة بشرية متخصصة للنصوص قبل إطلاق إصدار عام.

## حالة العمل
تمت الموافقة على السياسة، وليس على نسخ أي طبعة مجهولة الترخيص. لا تزال الأقسام الستة بحاجة إلى محتوى مرخص ومدقق، ويجب أن تظهر للمستخدم بوصفها غير متاحة حتى الانتهاء.
