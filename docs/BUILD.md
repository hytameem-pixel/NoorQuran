# بناء Android

1. أضف ملف قرآن موثقًا ومُرخصًا إلى `assets/content/quran/quran.json`، ثم اربطه بالتطبيق وفعّل تضمينه في `pubspec.yaml`.
2. افتح تبويب **Actions** في المستودع واختر **NoorQuran Android build**.
3. اختر **Run workflow**.
4. لن تُنشأ حزمة APK إلا إذا نجح التحقق من البيانات والاختبارات والبناء.

**تنبيه:** هذا مستودع تأسيسي. يلزم نقل/مراجعة وظائف المشروع الكامل قبل أن يكون تطبيقًا مفيدًا وقابلًا للإصدار. يجب توقيع الإصدارات بمفتاح مستدام قبل التوزيع العام.
