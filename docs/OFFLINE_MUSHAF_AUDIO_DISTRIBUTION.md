# نور القرآن — متطلبات التنفيذ والتحقق

## 1. مصحف دون اتصال
- المحتوى الحالي يضم نص القرآن العثماني كاملًا (114 سورة، 6236 آية) وبيانات بدايات 604 صفحات، ولكن **ليس صور صفحات مطابقة للطبعة الورقية**.
- متطلب القبول: إرفاق طبعة مصحف مرخصة كاملة للصفحات 1–604، أو محرك عرض مطابِق تمت مراجعته، مع كشف checksum وتحقق من جميع الصفحات.
- Android / iOS: يجب تضمين الصفحات المتحقق منها ضمن الحزمة لكي تفتح لأول مرة دون اتصال.
- PWA: تنزيل كامل لحزمة الصفحات بصورة اختيارية، ثم إثبات جاهزية العمل دون إنترنت فقط بعد تخزينها جميعًا والتحقق من سلامتها. لا تدّعِ أن التخزين دائم؛ قد يحذف المتصفح بياناته.
- لا تُستبدل الصفحة القرآنية بصورة مولّدة بالذكاء الاصطناعي.
- اختبارات قبول: قطع الإنترنت ثم فتح الصفحات 1 و2 و100 و300 و604، والتنقل عبر جميع الصفحات والبحث والفهارس.

## 2. القراء — تشغيل آية بآية
- الأولوية للشيخ ماهر المعيقلي.
- احتفظ بجدول لكل قارئ: هوية القارئ، مصدر التسجيل، رابط الترخيص، السورة، الآية، المسار، checksum، حالة التوفر.
- التلاوة الآية بآية تتطلب ملفات مستقلة مرخصة أو توقيتات آيات موثقة لتسجيل السورة. تقسيم الملف بالزمن اعتباطيًا مرفوض.
- وظائف واجبة: الضغط على الآية للتشغيل، تشغيل التالي، تكرار 1/3/5/10، توقف بين الآيات، سرعة القراءة، وإتاحة تحميل السورة أو الجزء أو المصحف.
- لا تعلن أن القراء أو التلاوة دون اتصال متاحون قبل تنزيل ملفات صحيحة والتحقق من الترخيص والمحتوى.
- حجم كل حزمة صوتية يُعرض قبل التنزيل؛ لا تُجبر المستخدم على تنزيل جميع القراء.
- اختبارات: 1:1 و2:255 و18:10 و36:1 و114:6 ومطابقة الصوت بالآية المقصودة.

## 3. توزيع التطبيق من موقعه
- رابط تنزيل APK عام، عبر HTTPS، لا يتطلب دخول GitHub.
- يجب نشر نسخة Release موقعة بمفتاح مستقر، والتحقق من package ID وversionCode وSHA-256.
- يمكن نشر APK على GitHub Releases وربط الموقع مباشرة بملف الإصدار، ثم إضافة PWA وApp Store عند توفرها.
- لا تنشر APK تلقائيًا إذا فشلت الاختبارات، أو لم يتوفر مفتاح التوقيع المناسب للتحديثات.
- لا تسمِ تشغيل الموقع عبر المتصفح تطبيقًا كاملًا دون دعم التخزين دون إنترنت.

## تقرير الحالة الحالي
- النص القرآني المضمّن: موجود، مشروط باجتياز اختبار سلامة البيانات.
- عدد 604 موضع صفحة: موجود؛ التخطيط الطباعي المطابق للطبعة: غير مكتمل.
- فهرس مستقل للبحث وفتح السور: أضيف إلى فرع التطوير.
- تلاوات ماهر المعيقلي آية بآية: غير متوفرة في أصول المستودع.
- تطبيق ويب / PWA: غير موجود في الفرع المرجعي؛ يجب تنفيذه واختباره.
- رابط تنزيل Android من الموقع: غير موجود قبل إعداد موقع نشر وإصدار عام.
