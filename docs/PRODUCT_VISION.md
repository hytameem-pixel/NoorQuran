# نور القرآن — وثيقة المنتج المعتمدة (Original Vision)

## الرؤية
تطبيق إسلامي عربي مجاني، مستقل الهوية، مستوحى من سهولة استكشاف المحتوى في تطبيقات القرآن الحديثة دون نسخ تصميم Quran.tv أو علامته أو أصوله. صدقة جارية على روح الوالد وعلى روح يحيى يحيى راجح تميم.

## مبادئ غير قابلة للتفاوض
- النص القرآني الأصلي Tanzil Uthmani كما هو دون تعديل. تحقق سلامة النص قبل كل بناء، والتزام نسبة المصدر والترخيص داخل التطبيق.
- القراءة متاحة دون تسجيل أو اتصال بالإنترنت، والملف الشخصي اختياري بالكامل.
- عدم جمع الهاتف أو البريد دون ضرورة فعلية؛ بيانات الجهاز المحلية يمكن حذفها.
- المحتوى المسموع والتفسيري والأذكار والأحاديث لا يُنشر دون مراجعة المصدر والحقوق.
- تصميم RTL عربي أولًا، وخط واضح، ودعم تكبيره والتباين وقارئات الشاشة والأجهزة الضعيفة.

## النسخة التأسيسية (Milestone 0.3)
1. شاشة رئيسية وهوية نور القرآن مستقلة.
2. فهرس 114 سورة بأسمائها الحقيقية، قراءة نص عثماني محفوظ، عرض رقم الآية والسورة.
3. بحث عربي دون تشكيل (فهرسة مساعدة خارج النص القرآني الأصلي).
4. علامات مرجعية متعددة وآخر موضع قراءة فعليًا مع العودة إليه.
5. إعدادات وضع ليلي/نهاري وحجم خط، محفوظة محليًا.
6. صفحة معلومات ومصدر القرآن وترخيص Tanzil وروابطه.
7. إخضاع هذه الوظائف لاختبارات وتحليل Flutter والبناء التجريبي على GitHub Actions.

## المراحل التالية
### 0.4 — المحتوى الشرعي
- تفسيرات من مصدر مرخّص وموثوق مع مراجعة مطابقة أرقام الآيات.
- تلاوات مسموعة مرخصة مع تشغيل وإيقاف وتنزيل اختياري عند الترخيص.
- أذكار وأدعية موثقة بمصادرها دون خلطها بالنص القرآني.
### 0.5 — التعلم والخدمة
- الحفظ والمراجعة والاختبار الاختياري، مشاركة الآيات بضوابط المصدر.
- إذاعة القرآن وقسم الأطفال؛ يحدد نطاقهما بعد تدقيق المحتوى.
### مستقبلًا
- الأحاديث ومواقيت الصلاة والقبلة والرقية الشرعية والمتون العلمية والترجمات وiOS ضمن مراحل مستقلة بعد ضبط المصادر والأذونات والتراخيص.

## تعريف الإنجاز
لا يُعد إنجاز مرحلة ناجحًا لمجرد إنتاج APK؛ يتطلب نجاح Flutter analyze/test والبناء وفحص القراءة على أجهزة Android حقيقية وتحقق المتطلبات الشرعية والخصوصية.

## مسؤولية العلامة
تطبيق نور القرآن مستقل وليس منتجًا تابعًا أو معتمدًا من Quran.tv.
