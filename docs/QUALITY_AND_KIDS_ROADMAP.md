# فحص الثغرات وخارطة الاستكمال — نور القرآن

## تم تنفيذه في فرع حفظ القرآن
- شاشة حفظ عامة وشاشة منفصلة للصغار من الصفحة الرئيسية.
- اختيار أي سورة، والتنقل بين الآيات، وإخفاء النص للتسميع الذاتي وإظهاره للمراجعة.
- تحديد الآية محفوظة أو تحتاج مراجعة؛ نسبة إنجاز السورة، وحفظ محلي دون تسجيل أو اتصال.
- عدم تعديل بيانات القرآن الأصلية أو جمع بيانات الطفل.

## ثغرات وضروريات باقية — لا يجوز وصفها بالمكتملة
### حرجة قبل النشر العام
1. توقيع Android للإنتاج وإعداد هوية الحزمة وتحديثات التطبيق دون فقد بيانات المستخدم.
2. تدقيق مستقل لعرض المصحف بالرسم العثماني وعلامات الوقف؛ اختبار أجهزة متعددة وإمكانية الوصول.
3. اختبار خصوصية نسخ Android الاحتياطية، والتخزين المحلي، وحذف البيانات، وملاءمة استخدام الأطفال.
4. ضمان عدم تسرب أي بيانات شخصية؛ لا يُطلب اسم الطفل أو بريده أو هاتفه.
5. توثيق المصدر وترخيص Tanzil داخل التطبيق وإشعار الحقوق.
6. اختبارات وحدات وواجهات للحفظ، وتوافق الإصدارات، وسلامة بيانات الحفظ عند التحديث.
### مطلوبة للنسخة التعليمية الكاملة
1. فصل ملفات تقدم عدة أطفال محليًا، مع إعدادات ولي الأمر دون إنشاء حسابات.
2. خطة حفظ أسبوعية وجدول مراجعة متباعدة وتنبيهات اختيارية غير مزعجة.
3. تسجيل محلي اختياري للتسميع بعد مراجعة أذونات الميكروفون وخصوصية الأطفال.
4. تلاوات مرخصة للآيات مع تكرار آية أو نطاق محدد؛ تنزيلات صوتية اختيارية.
5. التفسير الموثوق، والأذكار، والأحاديث، وتوثيق كل مصدر وترخيصه.
6. فهرس الأجزاء والأحزاب والصفحات، خط عثماني متخصص، بحث عربي متقدم، ودعم قارئات الشاشة.
7. آلية تنزيل وتحديث موثوقة (GitHub Releases أو متجر التطبيقات)، وصفحة خصوصية واضحة.
8. تحسين أداء عرض السور الطويلة وإدارة الذاكرة وإتاحة المشاركة المنضبطة.
9. تدقيق قانوني للعلامة المستقلة عن Quran.tv وحقوق الصور والصوتيات.

## معيار القبول
لا يكفي نجاح CI؛ يُشترط اختبار تثبيت وتشغيل APK على هاتف Android، ومراجعة قارئ القرآن من مختص، وتقييم تجربة ولي أمر وطفل تحت إشرافه.
