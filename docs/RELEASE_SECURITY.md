# شروط الإصدار

- لا تسجيل إلزاميًا؛ الاسم والهاتف والبريد اختيارية ومحلية فقط.
- SharedPreferences ليست مشفرة؛ لا تخزن أسرارًا أو بيانات حساسة.
- القرآن غير متوفر حاليًا: يلزم مصدر موثق وترخيص ومراجعة مستقلة.
- لا نشر قبل نجاح flutter analyze وflutter test وبناء APK وفحص جهاز حقيقي.
- التفسير والصوت والميزات الأخرى لم تُنفذ بعد.
- لا يمكن ضمان انعدام الثغرات أو تقييم 10/10 قبل اختبار مستقل.
