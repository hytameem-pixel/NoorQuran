# مقارنة موجزة بين GitHub وSites

| الجانب | GitHub قبل الدمج | مصدر Sites عند الإصدار 14 | نتيجة الفرع |
|---|---|---|---|
| الصفحة الرئيسية | بوابة تعريفية قصيرة | تطبيق ويب عربي كامل | نقل واجهة التطبيق إلى `website/` |
| المصحف والقرآن | بيانات تطبيق Android فقط | نص القرآن، فهرس الصفحات وملفات الخط | نُقلت صفحات الويب وبياناتها إلى `website/` |
| المكتبة الإسلامية | صفحات HTML أولية ومحتوى محدود | فهرس وبيانات متعددة الأجزاء | نُقلت ملفات المكتبة والفهارس؛ فصول gzip الكبيرة محفوظة ثنائيًا والصغيرة كنص Base64 |
| التطبيقات والتنزيلات | روابط وصفحات محدودة | صفحات حالة وفهارس وبصمات | نُقلت صفحات التطبيقات وفهارس التنزيلات إلى `website/`؛ ملفات APK وZIP (نحو 24.3 و24.4 MiB) بقيت مستضافة على Sites مع الأحجام والبصمات، لأن ترخيص إعادة توزيعها غير موثق؛ ملفات Android المصدرية في جذر المستودع لتجنب نسخة مكررة داخل Pages |
| اللغات | واجهة عربية فقط | محتوى عربي | أضيف مفتاح واجهة للعربية والإنجليزية واتجاه RTL/LTR؛ نصوص القرآن والحديث والمصادر تبقى بلغتها الأصلية، ولا تُترجم آليًا. يمكن إضافة لغة في قاموس `website/language.js` |
| التنقل | روابط بين صفحات متفرقة | تنقل ضمن التطبيق وروابط مستقلة | أضيف دعم مسارات مجلدات GitHub Pages |
| التحديث بين المصدرين | لا يوجد ربط | مستودع Sites داخلي | لقطة الإصدار 14؛ لا توجد مزامنة تلقائية مستمرة |

هذا الفرع لم يُدمج إلى `main`. GitHub Pages ينشر عند الدمج، بينما رابط Sites الأصلي لم يُغيّر.

## نتائج التدقيق والإصلاحات

| الملاحظة | الإجراء المنفذ | التحقق أو الحد |
|---|---|---|
| الفرع السابق كان بوابة وروابط تحويل، لا نسخة الموقع | نقل ملفات واجهة Sites وبياناتها إلى `website/` بدل الاكتفاء بتوجيه الزائر خارج GitHub | الشجرة النهائية تتضمن 1,188 ملف ويب مع إبقاء ملفات Android في الجذر |
| سير نشر Pages يرفع `website/` فقط | وضع الموقع الموحّد داخل مجلد النشر المحدد في Actions | لم يتغير سير العمل؛ النشر ما زال على `main` فقط |
| روابط الجذر في كتالوج التنزيلات لا تعمل تحت مسار المشروع، وبعض الروابط تخرج إلى `/` | ضبط أساس المسار والروابط في صفحات التنزيلات، وإصلاح تنقل أزرار الصفحة إلى روابط نسبية | فُحصت 104 إحالات HTML داخلية؛ لم يبقَ رابط محلي مفقود |
| بعض بيانات المكتبة نص Base64 وبعضها gzip ثنائي | جعل روابط الفهرس تطابق تمثيل الملف الفعلي، مع فك النص عند الحاجة والتحقق من SHA-256 | فُحصت 517 مادة مكتبة و604 ملفات صفحات للمصحف؛ اجتازت البايتات والبصمات وفك gzip وقراءة JSON |
| حجم الخطوط والتنزيلات كبير على المستودع | جلب 604 خط صفحة (نحو 95 MiB) من Quran Foundation بعد اكتشاف منع CORS على مضيف Sites، وإبقاء حزم APK/ZIP/الكتب الكبيرة على استضافة Sites | يلزم اتصال إنترنت لهذه المواد؛ اختُبر جلب الخطوط والتحقق من بصمات 4 صفحات. لم يُدّعَ أن APK نهائي أو معتمد |
| احتمال اختلاف محتوى القرآن بسبب النقل | التحقق من تجزئة Git للملف بعد رفعه | تطابق ملف `quran.json` المحلي مع blob في GitHub |
| سهولة الوصول والقراءة على الشاشات المختلفة | الحفاظ على رابط تخطّي المحتوى والتركيز المرئي ونقاط الاستجابة؛ دعم RTL/LTR | اختُبرت الواجهة السابقة على سطح المكتب؛ تعديلات اللغة الأخيرة اجتازت فحص صياغة JavaScript. معاينة githack ما زالت تعرض موارد مخبأة عند آخر محاولة؛ لم يُتحقق بصريًا من نسخة اللغة الأخيرة، ولم يُختبر هاتف فعلي |
| الأذكار الدينية | إظهار مجموعة HadeethEnc الحالية مع درجتها ومصدرها | المجموعة 158 مادة من الأدعية والأذكار وليست برنامجًا كاملًا لأذكار الصباح والمساء؛ حصن المسلم متاح كرابط PDF رسمي، ولا ندّعي اكتمال النص المحلي |
| مصداقية المحتوى والخصوصية | الإبقاء على بيانات المصدر والحالة في الفهارس، وعدم إضافة تسجيل أو جمع بيانات | يلزم فحص التراخيص قبل إعادة توزيع أي مادة من مصادرها |

## خطوات مراجعة المعاينة

1. افتح الصفحة الرئيسية، ثم جرّب روابط المصحف والمكتبة والتلاوات والتنزيلات والتطبيقات.
2. افتح `/apps/` و`/library/` و`/downloads/` مباشرة، ثم ارجع للرئيسية من كل مسار.
3. جرّب قراءة صفحة مصحف وفتح مادة مكتبة؛ الخطوط والتنزيلات الكبيرة تعتمد على استضافة Sites والاتصال بالإنترنت.
4. كرر التنقل بعرض جوال ولوحة مفاتيح، وتأكد من ظهور التركيز على العناصر.
5. لا تدمج الفرع أو تنشره إلى Pages قبل اعتماد المراجعة.
