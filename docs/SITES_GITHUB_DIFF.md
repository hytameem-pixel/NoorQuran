# مقارنة موجزة بين GitHub وSites

| الجانب | GitHub قبل الدمج | مصدر Sites عند الإصدار 14 | نتيجة الفرع |
|---|---|---|---|
| الصفحة الرئيسية | بوابة تعريفية قصيرة | تطبيق ويب عربي كامل | نقل واجهة التطبيق إلى `website/` |
| المصحف والقرآن | بيانات تطبيق Android فقط | نص القرآن، فهرس الصفحات وملفات الخط | نُقلت صفحات الويب وبياناتها إلى `website/` |
| المكتبة الإسلامية | صفحات HTML أولية ومحتوى محدود | فهرس وبيانات متعددة الأجزاء | نُقلت ملفات المكتبة والفهارس؛ فصول gzip الكبيرة محفوظة ثنائيًا والصغيرة كنص Base64 |
| التطبيقات والتنزيلات | روابط وصفحات محدودة | صفحات حالة وفهارس وبصمات | نُقلت الصفحات؛ خطوط المصحف وملفات APK وZIP الثقيلة بقيت على Sites؛ بيانات الصفحات والمكتبة متاحة محليًا |
| التنقل | روابط بين صفحات متفرقة | تنقل ضمن التطبيق وروابط مستقلة | أضيف دعم مسارات مجلدات GitHub Pages |
| التحديث بين المصدرين | لا يوجد ربط | مستودع Sites داخلي | لقطة الإصدار 14؛ لا توجد مزامنة تلقائية مستمرة |

هذا الفرع لم يُدمج إلى `main`. GitHub Pages ينشر عند الدمج، بينما رابط Sites الأصلي لم يُغيّر.
