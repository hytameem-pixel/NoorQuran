# توحيد موقع نور القرآن وGitHub

## النتيجة

أصبحت `website/index.html` بوابة ويب واحدة تصل إلى المصحف والتلاوات والمكتبة والتنزيلات ومعلومات تطبيق Android. المسارات القديمة للمكتبة وقصص الأذكار تحوّل الزائر إلى قسم المكتبة الحالي، وصفحتا التطبيقات توجّهان إلى صفحة التنزيلات الحالية. بذلك لا تعرض صفحات GitHub محتوى مكررًا قديمًا على أنه النسخة الكاملة.

الموقع الحالي الكامل محفوظ في Sites. يحتوي هذا المستودع أيضًا على تطبيق Android وملفات البناء والوثائق. تغيير الرابط أو محتوى بوابة GitHub لا يغيّر موقع Sites.

## ما لا يتزامن آليًا

مصدر Sites محفوظ في مستودع داخلي خاص بخدمة Sites، ولا يتوفر ضمن تكامل GitHub الحالي إجراء لإعادة ربط Sites بمستودع `hytameem-pixel/NoorQuran` أو دفع تغييرات المصدر بينهما تلقائيًا. لذلك هذا التغيير يدمج نقاط الوصول ويزيل صفحات الويب المكررة، لكنه لا ينسخ شيفرة الموقع كاملة إلى GitHub ولا يفعّل مزامنة ثنائية الاتجاه.

المزامنة الكاملة تحتاج دعم ربط مستودع GitHub داخل إعدادات Sites أو تصدير نسخة المصدر من Sites ثم استيرادها إلى هذا المستودع. احتفظ بعنوان الموقع الحالي أثناء أي نقل، ولا تنشر إصدارًا محفوظًا غير معتمد.

## تحقق قبل النشر

1. راجع الروابط من بوابة GitHub وصفحتي `/apps.html` و`/library/`.
2. تأكد أن الروابط تفتح على الهاتف والحاسوب وأن اتجاه RTL يعمل.
3. راجع حالة APK وبيانات مصادر القرآن قبل وصف أي ملف بأنه إصدار نهائي.
4. ادمج طلب المراجعة بعد اعتماد التغييرات؛ سير عمل GitHub Pages ينشر عند الدمج إلى `main`.
