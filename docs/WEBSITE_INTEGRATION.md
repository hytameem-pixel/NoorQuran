# دمج مصدر Sites مع GitHub

## ما تم استيراده

نُقلت واجهة موقع نور القرآن الثابتة من فرع Sites عند الإصدار 14، المصدر `326507f37390fd5a980ef0f3e324a434882bf0de`، إلى `website/`. تشمل النسخة الرئيسية، صفحات التطبيقات والتنزيلات، ملفات JavaScript وCSS، نص القرآن، فهرس المصحف وصفحاته وخطوطه، وفهارس وبيانات المكتبة. بقي مشروع Flutter في جذر المستودع دون تعديل.

أُنشئت صفحات مجلدات لـ `/apps/` و`/library/` و`/downloads/` لأن GitHub Pages لا يطبّق قواعد `_redirects` الخاصة باستضافة Sites. عُدّلت المسارات الداخلية لتعمل تحت مسار المشروع في GitHub Pages، وتم الإبقاء على فحوص SHA-256 للبيانات والتنزيلات حيث تنطبق.

## الملفات الكبيرة المستثناة

نُسخت البيانات المضغوطة وخطوط صفحات المصحف إلى GitHub بصيغة ملفات نصية Base64 بلاحقة `.b64.txt`، ويفكها قارئ الموقع قبل التحقق من بصمة SHA-256. حجم مصدر الويب الأصلي المنقول نحو 122 MiB؛ وتمثيل الملفات الثنائية كنص يزيد حجمها في المستودع بنحو الثلث. الملفات تُحمّل عند طلب الصفحة أو المرجع، لا دفعة واحدة عند فتح الموقع.

استُثنيت حزم APK وZIP وملفات الكتب المضغوطة الموجودة تحت `dist/downloads/` من GitHub. كان حجم هذا المجلد نحو 99 MiB عبر 21 ملفًا، ويشمل APK تجريبيًا بحجم يقارب 25 MiB، وحزمة مصدر بحجم يقارب 25 MiB، وحزمة مكتبة كاملة بحجم يقارب 18 MiB، إضافة إلى كتب مضغوطة ونسخ أقدم. روابطها في صفحة التنزيلات تشير إلى استضافة Sites الحالية، وتعرض الفهارس الحجم والبصمة ومصدر المحتوى.

بقية نسخة الويب المنقولة نحو 122 MiB عبر قرابة 1,790 ملفًا؛ يأتي معظم الحجم من خطوط صفحات المصحف. التنزيلات الصوتية لا تُخزّن ضمن المستودع؛ يستخدم الموقع فهرس التلاوات والمصادر الخارجية، ويحفظ الملفات على جهاز الزائر عند طلبه.

## الفروقات عن المستودع السابق

- كان GitHub يحوي مصدر تطبيق Flutter وصفحات ويب تعريفية محدودة، دون قارئ الويب الكامل أو بيانات المصحف والمكتبة اللازمة له.
- يحتوي Sites على تجربة الويب الكاملة وملفاتها. نُقلت هذه الملفات الآن إلى مجلد الويب في GitHub مع الحفاظ على تطبيق Android ووثائقه.
- حزم التنزيل الثقيلة ما زالت على Sites؛ لذلك يلزم الاتصال بموقع Sites لفتحها وتنزيلها.
- لا توجد مزامنة تلقائية ثنائية الاتجاه: مصدر Sites محفوظ في مستودع داخلي، ولا يتاح من تكامل GitHub الحالي ربطه مباشرةً بهذا المستودع. هذا الطلب يحتوي لقطة متزامنة من الإصدار 14، وأي تحديث لاحق يحتاج استيرادًا ومراجعة جديدة.

## مراجعة ما قبل النشر

1. راجع روابط الصفحة الرئيسية، المصحف، المكتبة، `/apps/`، `/library/`، و`/downloads/` من نسخة الفرع.
2. جرّب البحث والتنقل وحفظ الصفحات والمراجع وإدارة المساحة على الجوال والكمبيوتر.
3. جرّب روابط التنزيل الخارجية وتأكد من الاسم والحجم والبصمة في ملفات الكتالوج.
4. راجع مصادر النصوص وتراخيص الخطوط والكتب قبل أي إعادة توزيع.
5. لا تدمج طلب المراجعة أو تغيّر رابط Sites الأصلي حتى تعتمد النسخة.
